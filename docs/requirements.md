# Job-Lens 요구사항 명세서

> 버전: v0.2 | 작성일: 2026-06-03 | 작성자: 김기원

---

## 1. 프로젝트 개요

### 한 줄 정의
워크넷 채용공고 데이터를 기반으로 백엔드·QA·AI검증 직군의 기술 트렌드를 분석하고, 자연어 질의응답과 커리어 로드맵을 제공하는 채용시장 분석 플랫폼.

### 배경
백엔드·QA·AI검증 직군 취업을 준비하면서 수백 개의 공고를 개별 확인하는 과정이 비효율적이었음. "QA 엔지니어가 요즘 뭘 요구하지?", "AI 검증 직군은 Python을 얼마나 쓰지?" 같은 질문에 데이터 기반으로 답하는 도구가 없었음.

### 포지셔닝
"LangChain으로 RAG 만들었습니다"가 아니라
"백엔드·QA·AI검증 채용공고 500건을 분석해서 직무별 기술 트렌드를 추출하고 질의응답 시스템을 만들었습니다"

## 4. 기능 요구사항

### 4.1 데이터 수집 파이프라인 [MVP 필수]

- 워크넷 채용공고 API로 3개 직군 공고 수집
- 수집 항목: 회사명, 직무명, 요구 기술 스택, 경력 조건, 고용 형태, 지역, 공고 등록일
- SQLite에 원본 저장 (중복 제거: 공고 ID 기준)
- 기술 스택 정규화: `Java`, `JAVA`, `java` → `Java` / `Spring Boot`, `SpringBoot`, `Spring` → `Spring Boot`
- 수집 로그 출력 (수집 건수, 실패 건수, 소요 시간)

### 4.2 벡터 인덱싱 [MVP 필수]

- 공고 단위 청크 + 기술 스택 항목 분리 저장 (2-level 청크 전략)
- ChromaDB에 임베딩 저장, 메타데이터 인덱싱 (직군, 경력, 지역, 고용형태)
- 인덱싱 완료 후 총 벡터 수, 소요 시간 출력
- `/ingest` 엔드포인트로 수동 트리거 가능

### 4.3 RAG 질의응답 [MVP 필수]

- 자연어 질문 → 유사 공고 Top-K 검색 → Gemini 답변 생성
- 필터: 직군(backend/qa/ai_verification), 경력(신입/경력), 지역
- 답변에 참조 공고 출처 포함 (회사명)
- 예시 질문:
  - "QA 엔지니어가 가장 많이 요구받는 기술은?"
  - "AI 검증 직군은 Python을 얼마나 요구하나요?"
  - "백엔드와 QA의 기술 스택 차이는?"

### 4.4 기술 스택 Top N 조회 [MVP 필수]

- 직군별 요구 기술 빈도 Top N 반환
- 필터: 직군, 경력(신입/경력)
- 예시 응답:
  ```
  신입 QA 공고 143건 기준
  1. Python (67%)
  2. Selenium (54%)
  3. Jira (48%)
  4. Git (45%)
  5. SQL (39%)
  ```

### 4.5 커리어 로드맵 추천 [MVP 필수]

- "신입 백엔드 개발자가 가장 먼저 공부해야 할 기술은?" 형태의 질문에 공고 데이터 기반 로드맵 반환
- 단순 빈도 순위가 아니라 "먼저 배워야 할 것 → 이후에 배울 것" 순서로 구성
- 직군별 로드맵 제공 (백엔드 / QA / AI검증)

### 4.6 트렌드 분석 [MVP 필수]

- 최근 30일 공고 기준 기술 스택 변화 조회
- 직군별 필터 적용
- 구현은 집계 쿼리 수준으로 간단하게 (공수 최소화)

## 9. 면접 예상 Q&A

**Q. 왜 이 프로젝트를 만들었나요?**
AI 신뢰성 검증 직군에 관심이 생겨서 채용시장을 데이터 기반으로 분석해보고 싶었습니다. 직접 취업 준비를 하면서 느낀 불편함을 해결하는 도구를 만들었습니다.

**Q. RAG에서 ChromaDB를 선택한 이유는?**
2주 프로젝트에서 빠른 프로토타이핑이 필요했고, 로컬 설치가 가능하며 무료입니다. 프로덕션이라면 Pinecone이나 Weaviate를 고려했을 것입니다.

**Q. 검색 정확도를 어떻게 평가했나요?**
precision@k 지표로 Top-5 검색 결과 중 관련 공고 비율을 측정했습니다. 청크 전략(공고 단위 vs 기술 스택 분리)별로 비교 실험을 진행했습니다.

**Q. ChatGPT에 공고 붙여넣으면 되지 않나요?**
단건 질의는 그게 편합니다. Job-Lens는 500건 공고의 집계 인사이트를 제공합니다. "신입 QA 공고에서 Python 요구 비율이 67%"처럼 데이터 기반 트렌드 분석은 단건 붙여넣기로는 불가능합니다.
